Pin updater

Turns the pin spreadsheet into the file the globe reads. Everything happens in this browser; nothing is uploaded anywhere.

  1. Open data/pins.csv in Excel or Google Sheets, make your changes, and save or download it as CSV (in Excel, "CSV UTF-8" is best).
  2. Drop that file below. Fix anything listed in red.
  3. Click Download pins.js and replace data/pins.js with it (keep the name). Reload the globe.

    Lost the spreadsheet?

    Download the pins the globe is showing right now as a fresh pins.csv.

    Columns

    id stays the same for a pin forever (it is the link people share, like #japan-osaka-japan); use lowercase letters, numbers and dashes for new ones. latitude/longitude are decimal degrees (south and west are negative). mission_type is Defence/Peacekeeping, Commercial/Scientific or Medical/Disaster Relief. command is NORTHCOM, SOUTHCOM, EUCOM, AFRICOM, CENTCOM or PACOM. show_story is yes or no: with no, the card shows just the place and mission type; with yes it needs a headline and story. photo (optional) is a file in the photos/ folder, e.g. photos/concordia.jpg, with an optional photo_caption.
